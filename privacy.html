Kebijakan privasi Hermes

Berlaku sejak 13 Oktober 2026.

Apa yang dilakukan Hermes

Hermes mencatat tugas dan jadwal dari grup WhatsApp kuliah pemiliknya. Nama orang diganti kode sebelum diproses. Isi chat mentah terhapus otomatis setelah 90 hari. Hermes tidak membuat profil tentang orang dan tidak pernah mengirim pesan ke WhatsApp.

Data Google

  • Hermes hanya dipakai oleh pemiliknya sendiri.
  • Izin Google Tasks dipakai untuk membuat dan mengubah tugas di daftar "Hermes".
  • Izin Google Calendar dibatasi pada kalender yang dibuat Hermes sendiri (Hermes-Confirmed dan Hermes-Tentative). Hermes tidak bisa melihat kalender lain.
  • Hermes tidak membaca, menjual, atau membagikan data Google kepada siapa pun, dan tidak memakainya untuk iklan atau melatih model.
  • Token akses disimpan di server pribadi pemilik, hanya bisa dibaca akun pemilik. Pemilik bisa mencabutnya kapan saja di myaccount.google.com/permissions.

Penggunaan data dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

English summary

Hermes is a single-user personal tool. It only creates and updates tasks in the owner's "Hermes" task list and events in calendars it created itself. It cannot see other calendars. Google user data is never sold, shared, used for advertising, or used to train models. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
